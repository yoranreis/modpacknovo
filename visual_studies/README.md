# Caos Arcana — Biblioteca Visual de Estudos
**Server do Caos • RPG Mágico Medieval inspirado em Skyrim no Minecraft**

Esta pasta contém a biblioteca visual completa de estudos para o projeto **Caos Arcana**, desenvolvida a partir das diretrizes da `CAOS_ARCANA_Documentacao_Mestra.md`.

---

## 🌟 Como Navegar na Galeria Interativa

Para uma visualização ágil e organizada de todos os estudos, abra o arquivo local no seu navegador:

```
c:\Users\yurim\OneDrive\Desktop\caosmodpack\visual_studies\index.html
```

* **Filtros por Categoria:** Navegue facilmente entre Raças, Armaduras, Armas, Grimórios, Magias, Construções, Mapa, Dungeons, Provações, Eventos, Interfaces e Texturas Pixel Art.
* **Filtros por Status:** Separe o que já está *Decidido*, *Base Proposta* ou *Referência Proposta*.
* **Busca em Tempo Real:** Localize rapidamente por nome, id de asset ou palavra-chave.
* **Modal de Detalhes:** Clique em qualquer card para inspecionar a ficha técnica completa, resolução nativa, dependências de modelo/Fabric e abrir a imagem original em alta resolução.

## 📁 Estrutura de Diretórios

```
visual_studies/
├── index.html                   # Galeria local interativa (sem dependências externas)
├── CATALOGO_ASSETS.csv          # Catálogo completo estruturado em planilha (separador ;)
├── CATALOGO_ASSETS.json         # Catálogo completo em formato JSON para automações
├── README.md                    # Este guia de orientação
├── documentacao/                # Relatórios técnicos, guias e especificações
│   ├── GUIA_DIRECAO_DE_ARTE.md  # Regras visuais, anatomia, silhuetas e contrajogo
│   ├── PALETAS_E_MATERIAIS.md   # Códigos hexadecimais e materiais por cultura
│   ├── RELATORIO_COBERTURA.md   # Matriz de cobertura e registro de cota
│   ├── build_catalog.py         # Script gerador do catálogo CSV e JSON
│   └── build_gallery.py         # Script montador da galeria HTML
├── racas/                       # Concepts de personagens e anatomia sem armadura
├── armaduras/                   # Displays isolados de conjuntos pesados e leves
├── armas/                       # Conceitos de armas raciais e focos arcanos
├── livros/                      # Grimórios fechados e estudos de páginas abertas
├── magias/                      # Efeitos de conjuração, combate e barreiras
├── recursos/                    # Cadeia de fabricação, minérios e altares de mundo
├── construcoes/                 # Panorama da Cidade Central e assentamentos
├── mapa/                        # Mapa cartográfico conceitual com zonas e rotas de fuga
├── dungeons/                    # Ambientes subterrâneos e criptas ancestrais
├── provacoes/                   # Esquemas espaciais de arenas e desafios de maestria
├── eventos/                     # Esquemas táticos de disputa PvP e mockups de HUD
├── interfaces/                  # Mockups navegáveis de telas de GUI do jogo
├── texturas_pixelart/           # Texturas 32x32 repetíveis para blocos Minecraft
├── icones/                      # Sprites 32x32 com transparência para inventário
└── thumbnails/                  # Miniaturas otimizadas para navegação rápida
```
